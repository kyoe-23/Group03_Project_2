## 1. 파트 분배 (인당 1분)

가이드의 5장면 시간표(30초 · 30초 · 60초 · 30초 · 30초)를 앞에서부터 1분씩 자르면 정확히 3등분된다. 그래서 각자 자기 구간을 **한 번에 이어서** 녹음하고, 이어 붙이기만 하면 된다.

| 구간 | 담당 | 가이드 장면 | 기능 역할과의 연결 | 분량 |
|---|---|---|---|---|
| 0:00–1:00 | **정하나** | ① 문제 소개 (Hook) + ② 추상화·분해 | C · 영상·Miro. 노트북의 문제 정의, 사고 과정(Keep/Drop, IPO), 아키텍처 그림이 전부 이 구간의 화면이고, 영상 전체의 이야기를 여는 사람. C1(파이프라인 입구)도 하나 담당 | 약 50초에서 54초 |
| 1:00–2:00 | **안태현** | ③ 패턴·알고리즘·코드 (핵심 60초) | A · 데이터·로직. 더미 데이터, C2 `label_transactions`, C3 `mark_fixed_repeats`를 직접 짰으니 핵심 코드와 패턴 설명에 가장 적합 | 약 52초에서 56초 |
| 2:00–3:00 | **고준호** | ④ 결과 데모 + ⑤ 배운 점·한계 | B · 구현·통합. "모두 실행"으로 처음부터 끝까지 돌리고, C4·C5·`main`·테스트 결과를 보여 주며 마무리 | 약 55초에서 60초 |

<a id="sec3-temp-cell"></a>
### 화면용 임시 셀 (녹화용, 제출본에는 남기지 않기)

노트북에는 C3 전후를 비교해 보여 주는 셀이 없다. 녹화 직전에 **"3. C3" 코드 셀 바로 아래**에 셀을 하나 추가해 실행하고, 녹화가 끝나면 지운다. VS Code에서는 C3 코드 셀의 아래 가장자리에 마우스를 올리면 나오는 "+ 코드"를 눌러 셀을 만들고, Shift + Enter로 실행한다. 그 위의 셀들이 모두 실행된 상태여야 하고, 아래 출력은 실제로 실행해 확인한 결과다.

```python
before = label_transactions(clean_transactions(transactions), label_rules)
after = mark_fixed_repeats(before)
for b, a in zip(before, after):
    if b["is_discretionary"] != a["is_discretionary"]:
        print(b["month"], b["day"], b["merchant"], b["amount"], b["is_discretionary"], "→", a["is_discretionary"])
```

```
2026-07 15 쿠팡 와우멤버십 7890 True → False
2026-08 15 쿠팡 와우멤버십 7890 True → False
2026-09 15 쿠팡 와우멤버십 7890 True → False
```

<a id="sec3-adjust"></a>
### 줄이기 / 늘리기

- 줄이기 (길 때): "맞는 규칙이 없으면 기타, 고정입니다." 문장을 지우면 약 3초가 줄고, "거래 66건은 …" 문장 뒷부분(취소와 중복 설명)을 지우면 약 3초가 줄어든다.
- 늘리기 (짧을 때): C3 설명 뒤에 "C2는 하나 님이, C3는 준호 님이 리뷰했습니다."를 붙이면 약 4초가 늘고, 코드 리뷰를 했다는 점(협업 철칙 1)이 영상에 드러난다. 두 셀 첫 줄의 `# 담당 / 리뷰` 주석을 같이 보여 주면 근거가 된다.
- "쿠팡이츠는 식비로, 그 아래 쿠팡은 쇼핑으로" 대사가 나올 때 C2 코드에는 규칙표가 안 보인다. 1:00에 녹화한 `label_rules` 화면(쿠팡이츠 줄과 쿠팡 줄이 보이는 구간)을 3초쯤 편집에서 끼워 넣으면 대사와 화면이 맞는다.
- 이 파트는 가이드의 "핵심 60초"라서, 대사를 말하는 동안 화면에 **코드가 계속 보이게** 한다. 설명 없이 스크롤만 하면 감점 사례("화면 스크롤 난사")가 된다.

<a id="sec4-full"></a>
### 읽기용 전문

> 이제 직접 돌려 보겠습니다. 모두 실행을 누르면 더미 거래 66건이 C1부터 C6까지 흘러갑니다. 제가 맡은 C4는 재량 지출을 월별로 더해 넘기고, C5는 이번 달에서 최저 월을 빼 점수를 매깁니다. 그 결과가 이 한 줄입니다. 카페·간식, 이번 달 18만 7천 원, 최저 12만 원, 절감 여지 6만 7천 원, 점수 0.46으로 1위입니다. 식비는 0.34, 이번 달이 최저인 쇼핑은 후보에서 빠졌습니다. 후보가 없거나 값이 빠진 거래가 있어도 에러 없이 한 줄이 나옵니다. 성공 기준 세 가지를 모두 달성했습니다. 합치면서 날짜 오타 하나가 '절감 여지 없음'으로 묻히는 걸 발견해 main에 거래월 검사를 넣었습니다. 한계는 더미 데이터라는 점이라, 다음엔 실제 카드 내역으로 확장하겠습니다.


<a id="sec4-adjust"></a>
### 줄이기 / 늘리기

- 줄이기 (영상이 길 때): "식비는 0.34, …" 문장을 지우면 약 6초, "후보가 없거나…" 문장을 지우면 약 6초가 줄어든다.
- 늘리기 (영상이 짧을 때): 성공 기준 문장 앞에 "마지막 셀이 정상, 후보 0개, 빈 입력, 값 누락 네 가지를 한 번에 보여 줍니다."를 붙이면 약 6초가 늘고, 테스트 셀이 무엇을 하는지 설명된다.
- "합치면서 … 발견해"는 팀 경험에 맞게 바꿔도 된다. 실제로 본인이 겪은 통합 중 버그가 있으면 그것을 말하는 쪽이 더 설득력 있다.
- 성공 기준을 화면으로 보여 주고 싶으면 2:42에 노트북 첫 셀의 "성공 기준"으로 올라갔다가 내려오는 방법이 있지만, 스크롤이 길어서 권장하지 않는다. 테스트 출력을 보면서 말하는 쪽이 자연스럽다.

## 5. 공통 녹화 · 편집 팁

<a id="sec5-notebook"></a>
### 노트북 준비

- **녹화용 복사본을 쓴다.** "모두 실행"과 임시 셀 때문에 제출용 노트북의 출력과 실행 번호가 바뀔 수 있다. 제출본(`notebooks/card_saving_suggester.ipynb`)을 저장소 밖(예: 바탕화면)에 복사해서 VS Code로 열고, 제출본은 건드리지 않는다. 녹화가 끝나면 복사본은 저장하지 말고 닫고, `git status`로 제출본이 바뀌지 않았는지 확인한다.
- **커널을 미리 선택해 둔다.** 노트북 오른쪽 위의 커널 선택에서 Python 커널(3.10 이상, 설치할 라이브러리 없음)을 고르고 한 번 실행해 둔다. 이 과정을 안 해 두면 "모두 실행"을 누르는 순간 커널 선택 창이 영상에 나온다.
- 세 사람이 **같은 설정**으로 녹화해야 이어 붙였을 때 화면이 튀지 않는다. VS Code 확대 배율은 기본으로 둔다, 라이트 테마, 전체 화면으로 창 크기를 미리 맞춘다.
- 사이드바(Cmd/Ctrl + B), 하단 패널, 미니맵은 닫아서 노트북 본문이 화면을 꽉 채우게 한다. 이름이나 개인 정보가 보이는 탭, 파일 경로, 알림 팝업은 가린다.
- 녹화 시작 전에 "모두 실행"을 한 번 돌려 출력이 채워진 상태로 둔다. 준호 파트만 화면에서 "모두 실행"을 직접 누르며, 실행 대기 시간은 점프컷으로 줄인다.

### 녹음 · 편집

- VS Code 창만 골라서 녹화한다 (OBS의 창 캡처, Mac은 Cmd + Shift + 5의 선택 영역 녹화, Windows는 Win + G). 바탕화면이나 다른 앱이 같이 찍히지 않게 한다.
